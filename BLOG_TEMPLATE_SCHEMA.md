# Blog Template Schema

This document describes the JSON structure for blog posts generated by the Legals Bot.

## JSON Fields

### Metadata Fields

| Field | Type | Length | Description |
|-------|------|--------|-------------|
| `title` | string | 55-70 chars | H1 headline, SEO-optimized with focus keyword in first 60 chars |
| `slug` | string | URL-safe | WordPress URL slug (kebab-case, lowercase, hyphens only) |
| `meta_description` | string | 155-160 chars | Appears in Google search results, includes keyword and CTA |
| `seo_title` | string | Under 60 chars | Title tag for search engines, keyword near the start |
| `focus_keyphrase` | string | Variable | The primary SEO keyword or its natural variant |

### Content Organization

| Field | Type | Description |
|-------|------|-------------|
| `excerpt` | string | 2-3 sentence hook, includes keyword in first sentence. Used for search previews. |
| `categories` | array | 2-3 main topic categories (e.g., "Personal Injury", "Medical Malpractice") |
| `tags` | array | 10-15 tags including keywords, service types, locations, and related terms |
| `content` | string | Full HTML blog post (2,400+ words) with formatted sections |

## Content Structure

All blog posts follow this exact sequence:

1. **Introduction** (150-200 words)
   - Opens with pain point
   - Includes focus keyword in first 2 sentences
   - Transitions into body

2. **Our Services** (Multiple H3 subsections)
   - H2 heading: "Our [Service] Services"
   - Exactly 7 H3 sub-sections covering variants or locations
   - Each H3: 2-4 paragraphs under 200 words total
   - Minimum 1 internal link per H3 block

3. **Why Choose [Site Name]** (1 H2 section)
   - 3-4 paragraphs on trust, experience, results
   - Includes email CTA link

4. **How the Process Works** (1 H2 section)
   - Numbered list of 4-6 steps
   - 1-2 sentences per step

5. **FAQ Section**
   - H2: "Frequently Asked Questions"
   - Exactly 5 Q&A pairs
   - Q/A format: `<strong>Q:</strong>` and `<p>A:</p>`
   - Each answer: 40-80 words
   - 2+ internal links within FAQ

6. **Conclusion + CTA** (150-200 words)
   - Summarizes urgency
   - Email CTA included
   - 2-3 internal links

7. **Legal Disclaimer** (Always last)
   - H2: "Legal Disclaimer"
   - 2-3 sentences about informational nature of content

## Content Rules

### Length & Structure
- Minimum 2,400 words of readable text (excluding HTML tags)
- H2 for major sections, H3 for subsections
- No section over 300 words before new heading
- No paragraph over 200 words
- 75%+ of sentences under 20 words

### Keywords & LSI
- Focus keyword in: opening paragraph, at least one H2, naturally 3-5x total
- Include LSI/semantic variants throughout
- Geographic modifiers: blend service with US cities/states naturally
- Target [Service + Location] combinations

### Internal Links
- **Minimum 20 required** throughout the post
- Distributed across all sections
- Use natural, descriptive anchor text (never raw URLs)
- Format: `<a href="https://example.com">anchor text</a>`
- Avoid clustering links in one section

### Transition Words
- 30%+ of sentences must open with or contain transition words
- Examples: Additionally, Furthermore, However, Therefore, Conversely, As a result, etc.

## HTML Formatting

- Use `<h2>` for section headings
- Use `<h3>` for subsection headings
- Use `<p>` for paragraphs
- Use `<strong>` for bold emphasis
- Use `<ol>` for ordered lists, `<li>` for items
- Internal links: `<a href="URL">anchor text</a>`
- Email links: `<a href="mailto:email@example.com">email@example.com</a>`

## WordPress Integration

When imported into WordPress:

1. **Title field** ← `title` (H1 set automatically by WP, don't repeat in content)
2. **Slug field** ← `slug` (URL structure)
3. **Excerpt field** ← `excerpt` (search preview)
4. **Categories** ← `categories` (created if not exist)
5. **Tags** ← `tags` (created if not exist)
6. **Content field** ← `content` (HTML blog post)
7. **SEO plugin fields**:
   - Meta description ← `meta_description` (Yoast/Rank Math)
   - SEO title ← `seo_title` (Yoast/Rank Math)
   - Focus keyphrase ← `focus_keyphrase` (Yoast/Rank Math)

## Example Quality Checklist

Before publishing, verify:
- [ ] 2,400+ words
- [ ] 20+ internal links
- [ ] Focus keyword in opening paragraph
- [ ] 7 H3 blocks under "Our Services"
- [ ] 5 FAQs
- [ ] Email CTA present
- [ ] No phone numbers or WhatsApp links
- [ ] Legal disclaimer at end
- [ ] No paragraph over 200 words
- [ ] 75%+ sentences under 20 words
- [ ] Meta description 155-160 characters
- [ ] SEO title under 60 characters
- [ ] Valid JSON (no trailing commas, all strings escaped)
